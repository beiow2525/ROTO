# ナンバーズ攻略法

## 1. ゲーム概要

| 種類 | 桁数 | 賭け方 | 当せん条件 | 理論上の当せん確率(ストレート) |
|---|---|---|---|---|
| ナンバーズ3 | 3桁(000〜999) | ストレート/ボックス/セット/ミニ | 数字の一致 | 1/1,000 |
| ナンバーズ4 | 4桁(0000〜9999) | ストレート/ボックス/セット | 数字の一致 | 1/10,000 |

- **ストレート**: 数字と順序が完全一致
- **ボックス**: 数字の組み合わせのみ一致(順序不問)。同じ数字の並びの出現パターン数によって「6ボックス」「3ボックス」「1ボックス(ゾロ目)」などに分かれ、当せん金が変わる
- **セット(ストレート＋ボックス)**: 1口でストレートとボックスの両方を購入する形
- **ミニ(ナンバーズ3のみ)**: 下2桁のみを指定

ロト系と違い、ナンバーズは各桁が独立した数字を選ぶ形式で、理論上の当せん確率は固定(1/1,000、1/10,000)です。ここが「数字の出方を工夫する」余地がある部分です。

## 2. ボックス購入で当せん確率を実質的に上げる

ストレートの確率は数字を変えても1/1,000で一定ですが、**ボックスで購入する場合、同じ数字が重複しない組み合わせ(例: 1-2-3)を選ぶと、当せん確率が最大化**されます。

- 全て異なる数字(例: 123) → 並び替えが6通り → ボックス的中確率 6/1,000
- 2つが同じ数字(例: 122) → 並び替えが3通り → ボックス的中確率 3/1,000
- 3つとも同じ(ゾロ目、例: 111) → 並び替えが1通り → ボックス的中確率 1/1,000(その代わり当せん金は高め)

**ポイント**: ボックス購入で当せん率を重視するなら、0〜9の中から重複しない3つ(または4つ)の数字を選ぶのが最も的中しやすい。ただし当せん金はストレートやゾロ目ボックスより低く配分される点とのトレードオフになります。

## 3. 過去の出現データを使う考え方

各桁(百の位・十の位・一の位)ごとに、過去の当せん数字の出現頻度を集計する方法があります。

- **頻度分析**: 各桁について0〜9の出現回数を集計し、「よく出ている数字(ホットナンバー)」「しばらく出ていない数字(コールドナンバー)」を可視化する
- **コールドナンバー狙い**: 統計的な裏付けは弱いものの、「そろそろ出るのでは」という心理に基づき、長期間出現していない数字を組み合わせに入れる人が多い
- **合計値分布**: ナンバーズ3で各桁の合計(0〜27)を見ると、中央値付近(12〜16程度)に分布が偏りやすい(組み合わせ数が多いため)。合計値が極端に低い/高い数字は組み合わせパターンが少なく出現頻度が低い

注意: これらは「過去のデータの偏り」であり、次回の抽せん確率には影響しません。ただし、**購入者側の数字選択の偏りを避ける**という意味では有効です(次項参照)。

## 4. 「人と数字が被らない」ための工夫(山分け対策)

ナンバーズは当せん金が「当せん口数に応じて変動する」パリミュチュエル方式です。多くの人が選ぶ数字(誕生日由来の1〜31、ゾロ目、111・777などの縁起の良い数字、123などの並び)は当せん時に当せん金が分散しやすくなります。

- 誕生日に収まらない数字(8以上を含む組み合わせ)を混ぜる
- ゾロ目・階段状の並び(123, 234など)を避ける
- 語呂合わせで人気の出やすい数字(0000, 1111, 7777等)を避ける

これにより、当せん確率自体は変わりませんが、**当せんした場合の1口あたり受取額の期待値**を改善できます。

## 5. 資金管理

- ミニ(下2桁)は当せん確率が1/100と高いため、少額で当せん経験を積みたい人向け
- ストレートは配当が大きい分当せん確率が低いため、余剰資金の一部に留める
- ボックス+ストレートの「セット買い」は、外れリスクを抑えつつボックスの的中も狙える折衷案
