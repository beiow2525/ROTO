# ロト6攻略法

## 1. ゲーム概要

- 1〜43の数字から**異なる6個**を選択
- 抽せんで6個の本数字＋2個のボーナス数字が発表される
- 組み合わせ総数: 43C6 = 6,096,454通り(1等の理論上当せん確率 約1/6,096,454)

| 等級 | 条件 |
|---|---|
| 1等 | 本数字6個一致 |
| 2等 | 本数字5個＋ボーナス数字1個一致 |
| 3等 | 本数字5個一致 |
| 4等 | 本数字4個一致 |
| 5等 | 本数字3個一致 |

## 2. 数字選択の基本テクニック

### (1) ゾーン分散
1〜43を4〜5個のゾーン(例: 1-9, 10-18, 19-27, 28-35, 36-43)に分割し、各ゾーンから満遍なく数字を選ぶ方法です。全数字が1つのゾーンに集中する組み合わせは、統計的な出現頻度が低い傾向にあります。

### (2) 奇偶バランス
6個中、奇数と偶数の比率は「3:3」「4:2」「2:4」あたりに収束しやすいのが過去の傾向です。全部奇数・全部偶数の組み合わせは稀にしか出現しません。

### (3) 合計値のレンジ
6個の合計値は理論上6〜258の範囲ですが、出現頻度で見ると**中央値付近(概ね120〜160程度)**に偏りが見られます。極端に小さい数字(1〜10台)や大きい数字(30台後半〜40台)ばかりで固めると合計値が偏り、出現しやすい範囲から外れます。

### (4) 連続数字の出現率
過去データでは、6個のうち2個が連続する数字(例: 14, 15)が含まれるケースは一定の頻度で発生しますが、3個以上連続するケースは大きく減少します。連続数字を1組程度含めるのは統計的に自然な範囲内です。

### (5) 前回・前々回との重複を確認する
直近の当せん番号とまったく同じ数字を複数含めた組み合わせを避ける、または逆に「1〜2個は直近の当せん数字から引き継ぐ」等、独自ルールを決めて一貫させる人もいます(統計的根拠は限定的ですが、選択基準を固定化する目的で使われます)。

## 3. ホイーリングシステム

ロト6は6個選択のため、候補数字を8〜12個程度に絞り込み、そこから複数の6個組み合わせを生成するホイーリングが有効です。

- **キー数字固定型ホイール**: 「これは絶対入れたい」という数字(キーナンバー)を1〜2個固定し、残りの候補から組み合わせを生成する
- **フルホイール**: 候補数字全ての組み合わせを購入(候補を10個にすると210通りになるため、予算と相談)
- **短縮ホイール**: 市販・ネット上のホイーリング表を使い、一定の当せん保証条件下で口数を抑える

## 4. クイックピック(自動選択)との比較
ロト6は自動選択(クイックピック)の当せん者も多く、機械的にランダムな数字が選ばれるため、購入者間の数字の偏りが少なくなります。自分で数字を選ぶ場合は、上記の分析を活かしつつ、**人気の出やすい数字(誕生日由来の1〜31、ゾロ目、規則的な並び)を意図的に外す**ことで、当せん時の山分けリスクを下げられます。

## 5. 資金管理
- 継続買い(同じ数字を毎回購入)は、長期的に特定の組み合わせが出た際の後悔を避けたい人向け
- ホイーリングを使う場合は口数が増えやすいため、月間予算を先に固定する
- キャリーオーバー発生時(1等該当者なしで賞金が次回に持ち越された回)は理論上の当せん金期待値が上がるため、購入タイミングとして着目されることが多い
