# ミニロト攻略法

## 1. ゲーム概要

- 1〜31の数字から**異なる5個**を選択
- 抽せんで5個の本数字＋1個のボーナス数字が発表される
- 組み合わせ総数: 31C5 = 169,911通り(1等の理論上当せん確率 約1/169,911)

| 等級 | 条件 |
|---|---|
| 1等 | 本数字5個一致 |
| 2等 | 本数字4個一致＋ボーナス数字一致 |
| 3等 | 本数字4個一致 |
| 4等 | 本数字3個一致 |

## 2. 数字選択の基本テクニック

### (1) 番号範囲のバランス
1〜31を「1〜10」「11〜20」「21〜31」のような3つのゾーンに分け、各ゾーンから偏りなく数字を選ぶと、過去の当せん番号の分布に近い形になりやすいとされています。極端な例(1,2,3,4,5のような連続した小さい数字のみ)は理論上の出現確率は他の組み合わせと同じですが、購入者間で選ばれやすく山分けの対象になりやすい傾向があります。

### (2) 奇数・偶数のバランス
5個の数字の奇偶比率は「3:2」または「2:3」に収束しやすいというのが長期データの傾向です(全部奇数・全部偶数は組み合わせ数が少ないため出現頻度が低い)。極端な偏り(5個全て奇数、または全て偶数)を避け、3:2程度のバランスを意識する人が多いです。

### (3) 合計値のレンジ
5個の数字の合計は理論上5〜155の範囲を取りますが、組み合わせ数の都合上、**中央値付近(概ね70〜100程度)に分布が集中**しやすくなっています。合計値がこのレンジに収まるよう数字を選ぶと、統計的に出現頻度の高い組み合わせパターンに近づきます。

### (4) ホット・コールドナンバー分析
過去数十回分の当せん番号を集計し、出現頻度の高い数字(ホット)・低い数字(コールド)を洗い出す方法です。

- ホットナンバー中心: 直近のトレンドに乗る考え方
- コールドナンバー中心: 「そろそろ出る」という発想(根拠は薄いが実践者は多い)
- 両者をミックスして5個を構成するのが一般的なアプローチ

## 3. ホイーリングシステム(組み合わせ購入法)

複数口を購入する場合、候補となる数字を多めに選び(例: 7〜10個)、その中から一定のルールで複数の5個組み合わせを機械的に生成する「ホイーリング」という手法があります。

- **フルホイール**: 選んだ候補数字の全組み合わせを購入(網羅的だが口数が多くなる)
- **アブリビエイテッドホイール(短縮ホイール)**: 一定の当せん保証条件(例: 候補数字のうち3個が本数字に入っていれば必ず4等以上が1口当たる、等)を満たす範囲で口数を絞った購入パターン

ミニロトは1口200円と安価なため、10個の候補から複数口を購入するホイーリングは比較的実践しやすいゲームです。

## 4. 山分けリスクを避ける選び方
- 誕生日(1〜31)に収まる数字だけで構成しない(全部が31以下なので工夫しづらいが、規則的な並びは避ける)
- 1,2,3,4,5や5,10,15,20,25のような規則的パターンを避ける
- 語呂の良い数字の組み合わせを避ける

## 5. 資金管理の考え方
- 1口200円という手軽さを活かし、毎回同じ数字を継続して買う「据え置き買い」と、都度分析して変える「都度買い」のどちらかを決めて一貫させる
- ホイーリングで口数を増やす場合は、月あたりの予算上限を先に決めておく
