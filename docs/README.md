## 大前提（必ず読んでください）

すべてのガイドに共通する事実として、以下を最初に明記します。

1. **抽せんは毎回独立したランダム事象です。** 過去にどの数字が出たかは、次回の当せん確率に一切影響しません（ギャンブラーの誤謬）。
2. **どの数字を選んでも「当せん確率」自体は変えられません。** ここで紹介する手法は、当せん確率を上げるものではなく、(a) 当せん時に他の当せん者と賞金を分け合う確率を下げる「山分けリスク軽減」、(b) 資金管理、(c) 買い方の効率化を目的とした考え方です。
3. **期待値は控除率(50%前後)の分だけ必ずマイナスです。** 宝くじは投資商品ではなく、エンターテインメントとして「余剰資金の範囲で」楽しむものと位置づけてください。

この前提を踏まえた上で、各ゲームのページでは具体的な数字選択のテクニックを解説します。
