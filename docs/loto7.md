# ロト7攻略法

## 1. ゲーム概要

- 1〜37の数字から**異なる7個**を選択
- 抽せんで7個の本数字＋2個のボーナス数字が発表される
- 組み合わせ総数: 37C7 = 10,295,472通り(1等の理論上当せん確率 約1/10,295,472)

| 等級 | 条件 |
|---|---|
| 1等 | 本数字7個一致 |
| 2等 | 本数字6個＋ボーナス数字1個一致 |
| 3等 | 本数字6個一致 |
| 4等 | 本数字5個一致 |
| 5等 | 本数字4個一致 |
| 6等 | 本数字3個＋ボーナス数字1個一致 |

ロト7はロト6よりさらに当せん確率が低い分、理論上の還元率(控除率)がキャリーオーバー時に有利になりやすい設計です。

## 2. 数字選択の基本テクニック

### (1) ゾーン分散
1〜37を5ゾーン程度(例: 1-7, 8-14, 15-21, 22-28, 29-37)に分け、各ゾーンから1〜2個ずつ選ぶと、極端な偏りを避けられます。

### (2) 奇偶バランス
7個という奇数個の選択のため、奇偶比率は「4:3」または「3:4」に収束しやすい傾向があります。

### (3) 合計値のレンジ
7個の合計値は理論上7〜238ですが、出現頻度で見ると**中央値付近(概ね110〜160程度)**に集中しやすい特性があります。

### (4) ボーナス数字の扱い
ロト7はボーナス数字が2個(本数字に隣接する数字が自動的に対象になるわけではなく、抽せん時に別途2個引かれる)あるため、2等の当せんチャンスがロト6よりやや広くなっています。本数字6個一致を狙う設計というより、7個全体のバランスを意識した選び方が基本です。

## 3. ホイーリングシステム

7個選択で組み合わせ数が多くなるため、ホイーリングの効果(口数対効率)が特に出やすいゲームです。

- 候補数字を9〜14個程度に絞り込み、フルホイールまたは短縮ホイールで複数口を生成
- キーナンバー(固定数字)を2〜3個決め、残りの候補から組み合わせを作る「キー数字固定型」が口数を抑えつつ的中率を確保しやすい
- ロト7は1口300円のため、口数が増えるホイーリングは予算管理が特に重要

## 4. 山分けリスクを避ける選び方
- 誕生日に収まらない数字(32〜37)を意識的に含める
- 規則的な並び(1,8,15,22,29など等差数列)を避ける
- ゾロ目的な語呂の良い数字列を避ける

## 5. キャリーオーバーとの付き合い方
ロト7は1等が出ない場合にキャリーオーバーが発生しやすく、繰越金が積み上がると1等の期待値(理論上の当せん金)が大きく上昇します。長期的に見て、**キャリーオーバー発生中の回に絞って購入する**のは、資金効率の観点で合理的な戦略の一つとされています(当せん確率自体は変わりませんが、当せん時の金額期待値が上がるため)。

## 6. 資金管理
- 1口300円と他のロトより高めなので、月間予算の上限設定が特に重要
- ホイーリングで口数を増やす場合、キャリーオーバー発生時に予算を厚めに配分するなど、メリハリをつける人が多い
