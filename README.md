## 分析ツール

[tool/index.html](./tool/index.html) はブラウザで開くだけで動く自己完結型の数字分析ツールです(ミニロト/ロト6/ロト7対応)。過去データの頻度分析・奇偶バランス・合計値分布・ゾーン分布を可視化し、統計傾向に基づく候補番号の生成やホイーリング(組み合わせ購入)を支援します。当せん確率自体を高めるものではない旨はツール内にも明記しています。
